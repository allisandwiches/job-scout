# How to post this kit on GitHub (no coding required)

This guide is for whoever is **publishing** the kit so others can download it. If you just want to *use* the kit, go back to the [main README](../README.md).

GitHub is a free website for sharing projects. Everything below happens in your web browser.

---

## 1. Make a free GitHub account
Go to [github.com](https://github.com) → **Sign up**. Pick a username, verify your email, done.

> 🔒 **Privacy tip:** Your username and profile are public. You don't need to use your real name. In **Settings → Emails**, turn on **"Keep my email addresses private."**

## 2. Create a new repository
A *repository* ("repo") is just a project folder on GitHub.

1. Click the **+** in the top-right → **New repository**.
2. **Repository name:** `job-scout` (or anything you like).
3. **Description:** *A no-code AI job search assistant for creatives.*
4. Choose **Public** so others can find it.
5. Leave the other boxes unchecked. Click **Create repository**.

## 3. Upload the files
1. On your new, empty repo page, click the link **"uploading an existing file."**
2. Unzip the kit on your computer.
3. Open the unzipped `job-scout` folder, select **everything inside it** (the files *and* the `examples` and `guides` folders), and drag it all onto the GitHub page.
4. Wait for the uploads to finish.
5. Scroll down. In the box under **Commit changes**, type a short note like *Add Job Scout kit*.
6. Click the green **Commit changes** button.

Your repo page now shows the README as its homepage. 🎉

## 4. Before you share — quick privacy check
Open each file on GitHub and make sure none of these slipped in:
- [ ] Your name, email, phone number, or address
- [ ] Your resume
- [ ] Your real filled-in settings file (share the **blank** template only)
- [ ] Your real application tracker
- [ ] Specific jobs you've applied to

If something slipped in: open the file → click the **pencil ✏️** icon to edit it, or the **⋯ → Delete file** to remove it → **Commit changes**.

> ⚠️ GitHub keeps a history of every version. If something truly sensitive (like a phone number) was uploaded, the safest fix is to **delete the whole repository** (Settings → scroll to the bottom → *Delete this repository*) and upload a clean copy.

## 5. Share the link
Copy the address from your browser bar (it looks like `github.com/your-username/job-scout`) and post it wherever — Discord, LinkedIn, a class group chat. Anyone can click **Code → Download ZIP** to get the kit, no account needed.

## 6. Updating later
To change a file: open it on GitHub → **pencil ✏️** icon → edit → **Commit changes**.
To add a file: repo homepage → **Add file → Upload files**.
